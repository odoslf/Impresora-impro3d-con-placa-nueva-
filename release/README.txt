Odos3D-Lab - firmware final
Base: Marlin 2.1.2.8
Placa: BIGTREETECH SKR 1.4 Turbo / LPC1769
Drivers: BIGTREETECH TMC2209 V1.3 UART
Archivo para SD: firmware.bin
HEATER_0_MINTEMP: 1 C
BED_MINTEMP: 1 C

Copiar firmware.bin a la raiz de una microSD FAT32, con la impresora apagada.
Insertar la microSD en la SKR y encender. La placa renombra el archivo tras flashear.
